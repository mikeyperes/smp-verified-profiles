# Podcast backend contract

The Podcast tab renders only `<div id="smp-vp-podcast-settings"></div>`. No screen design or new visitor styling is included. Existing profile templates and standard fields are reused unchanged.

## Saving

POST to WordPress `admin-ajax.php` with action `smp_verified_profiles_save_podcast`, `enabled=0|1`, and `nonce` generated by `wp_create_nonce('smp_verified_profiles_podcast')`. Requires an authenticated user with `manage_options`. Wrong capability returns 403; invalid enabled returns 400; invalid nonce uses the WordPress nonce error. Success is `{"success":true,"data":{"enabled":true,"post_type":"podcast-guest"}}` (enabled reflects the requested boolean).

Storage is the existing Core content-type settings option `smp_vp_content_type_settings`, entry `podcast-guest`. `ProfileTypes` supplies the managed Podcaster preset and `/guest/` rewrite, off by default. `PodcastSection::set_enabled(bool)` is the same storage path for authorized programmatic callers. The next request registers or hides the type and regenerates rewrite rules. Disabling never deletes posts. The Custom Post Types registry is the authority; no parallel toggle is stored.

`ProfileTypes::guest_type()` returns `podcast-guest` when enabled, otherwise an empty string. EpisodeData owns all episode relationships and the three legacy Elementor query IDs. Episode settings determine its episode post type. Without the separate Podcast type, existing active profile types remain eligible for backward compatibility.

## Migrated addresses

Only published guests marked `_smp_vp_guest_migrated` redirect from their previous profile slug (option `smp_vp_guest_legacy_slug`, default `profile`) to their current permalink. Unmigrated verified profiles and unknown addresses are untouched. Redirects are 301 and disabled while guests are hidden.

When Rank Math is active, the explicit Podcast toggle also saves `pt_podcast-guest_sitemap` in its sitemap settings and invalidates its sitemap cache after rewrite registration. No other sitemap choice changes.

The migrated-address handler runs on `wp` at priority 1, before Rank Math historical redirections. It applies only to marked migrated guests and never changes the stored Rank Math rules.
